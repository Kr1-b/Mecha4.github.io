# Mecha4 robotic fish

Website and files for our MEC 482 Mechatronics project at Abu Dhabi University (Fall 2026): a 3D-printed robotic fish with a crank and slotted-yoke tail drive, a rudder, two side fins, and phone control through an ESP32, an HC-12 radio and an Arduino UNO.

Live site: https://kr1-b.github.io/Mecha4.github.io/

| Folder | What is in it |
| --- | --- |
| `index.md` | Home page (course template: Introduction, Research Question, Background, Results, Conclusions, External Links, References) |
| `how-it-works.html`, `electronics.html`, `build-log.html`, `files.html` | The other pages |
| `_layouts/` | Shared page layout (header, menu, footer) |
| `assets/` | CSS, scripts, images, videos and the 3D model |
| `cad/` | STL files for every printed part |
| `code/` | Arduino code for the ESP32 transmitter and the UNO receiver |
