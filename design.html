    How it fits together

    The dry box replaces the solid block in the current body. The tail crank shaft leaves through the rear gland, so the existing crank and tail keep working as in the dynamic simulation.

    Each fin hub slides onto a 3 mm D-shaft and is locked with an M3 set screw on the flat. Inside, the shaft couples to an SG90 servo horn mounted on the printed bracket.

    In Inventor: open each STEP with File → Open, save it as a part, then place it in fish flapping.iam. Add a revolute joint on each shaft axis and drive it in Dynamic Simulation.
